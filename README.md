# Обновление сайта

Требуются Python 3, Git и настроенный доступ к GitHub.
Все команды ниже запускаются из папки проекта в PowerShell.

## Обновить CV

```powershell
.\update-cv.cmd "D:\Мои доки\Симагамбетов_Нартай_CV.pdf"
```

Команда проверит PDF, заменит `assets/cv.pdf` и обновит версию ссылки по содержимому файла, чтобы браузер скачивал новую версию.

Обновить и сразу отправить на GitHub:

```powershell
.\update-cv.cmd "D:\Мои доки\Симагамбетов_Нартай_CV.pdf" -Publish
```

CV и текст сайта обновляются отдельно: загрузка PDF не извлекает из него данные.

## Изменить данные

Редактируйте `content.json` в любом текстовом редакторе:

- `contacts` — телефон, подпись телефона, email, ссылки Telegram и WhatsApp.
- `cv` — путь к PDF и имя при скачивании.
- `photo` — путь к фотографии.
- `educationYears` — годы окончания обучения.
- `stack` — технологии, сгруппированные по категориям.
- `languages.ru`, `languages.kk`, `languages.en` — тексты на трёх языках.
- В каждом языке `title`, `description`, `aria` — заголовок, описание и подписи доступности.
- В `sections`: `position` — должность, `tagline` — краткое описание, `about` — о себе; `experienceDates`, `experienceCompanies`, `experienceRoles`, `experienceDetails` — опыт работы.

Например, должность:

```json
"position": ["Руководитель ИКТ · DevOps / DBA"]
```

Каждый элемент `experienceDetails` — массив отдельных достижений для одного места работы. Можно добавлять и удалять достижения в этом массиве. В остальных массивах сохраняйте количество и порядок элементов: они соответствуют существующим блокам сайта. Новое место работы или раздел требует изменения шаблона.

Тексты могут содержать HTML, например `<br>` или существующие счётчики `<span class="counter" ...>`. Сохраняйте их при редактировании. Общие контакты, стек и годы меняются один раз; переводимые тексты редактируются на каждом языке.

Собрать сайт и проверить данные:

```powershell
python tools/build.py
python tools/build.py --check
```

Откройте `index.html` в браузере для предварительного просмотра — работает и без локального сервера.

## Опубликовать

```powershell
.\publish.cmd
```

Команда соберёт и проверит сайт, создаст коммит и отправит текущую ветку в GitHub. Публикация на сайте зависит от настроенной ветки GitHub Pages; для этого проекта используется `main`. Если есть ранее подготовленные к коммиту изменения, команда остановится, чтобы не включить их случайно. При ошибке отправки локальный коммит сохранится — команду можно повторить.

## Для разработки

`content.json` — источник данных. `tools/index.template.html` — шаблон оформления. `index.html` и `content.js` создаются сборкой: не редактируйте их вручную. `i18n.js` отвечает за переключение языков, `tools/content-selectors.json` связывает названия полей с элементами страницы.

Старая копия `assets/Симагамбетов_Нартай_CV.pdf` оставлена для совместимости с прежними прямыми ссылками. Кнопка сайта использует только `assets/cv.pdf`; при сборке копия тоже обновляется автоматически.
