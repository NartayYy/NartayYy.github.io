# Обновление сайта

Требуются Python 3, Git и настроенный доступ к GitHub.
Все команды ниже запускаются из папки проекта в PowerShell.

## Обновить CV

```powershell
.\update-cv.cmd "D:\Мои доки\Симагамбетов_Нартай_CV.pdf"
```

Команда проверит PDF, заменит `assets/cv.pdf` и обновит версию ссылки по содержимому файла, чтобы браузер скачивал новую версию.

Обновить и сразу отправить на GitHub:

```powershell
.\update-cv.cmd "D:\Мои доки\Симагамбетов_Нартай_CV.pdf" -Publish
```

CV и текст сайта обновляются отдельно: загрузка PDF не извлекает из него данные.

## Изменить данные

Редактируйте `content.json` в любом текстовом редакторе:

- `contacts` — телефон, подпись телефона, email, ссылки Telegram и WhatsApp.
- `cv` — путь к PDF и имя при скачивании.
- `photo` — путь к фотографии.
- `educationYears` — годы окончания обучения.
- `stack` — технологии, сгруппированные по категориям.
- `languages.ru`, `languages.kk`, `languages.en` — тексты на трёх языках.
- В каждом языке `title`, `description`, `aria` — заголовок, описание и подписи доступности.
- В `sections`: `position` — должность, `tagline` — краткое описание, `about` — о себе; `experienceDates`, `experienceCompanies`, `experienceRoles`, `experienceDetails` — опыт работы.

Например, должность:

```json
"position": ["Руководитель ИКТ · DevOps / DBA"]
```

Каждый элемент `experienceDetails` — массив отдельных достижений для одного места работы. Можно добавлять и удалять достижения в этом массиве. В остальных массивах сохраняйте количество и порядок элементов: они соответствуют существующим блокам сайта. Новое место работы или раздел требует изменения шаблона.

Тексты могут содержать HTML, например `<br>` или существующие счётчики `<span class="counter" ...>`. Сохраняйте их при редактировании. Общие контакты, стек и годы меняются один раз; переводимые тексты редактируются на каждом языке.

Собрать сайт и проверить данные:

```powershell
python tools/build.py
python tools/build.py --check
```

Откройте `index.html` в браузере для предварительного просмотра — работает и без локального сервера.

## Опубликовать

```powershell
.\publish.cmd
```

Команда соберёт и проверит сайт, создаст коммит и отправит текущую ветку в GitHub. Публикация на сайте зависит от настроенной ветки GitHub Pages; для этого проекта используется `main`. Если есть ранее подготовленные к коммиту изменения, команда остановится, чтобы не включить их случайно. При ошибке отправки локальный коммит сохранится — команду можно повторить.

## Для разработки

`content.json` — источник данных. `tools/index.template.html` — шаблон оформления. `index.html` и `content.js` создаются сборкой: не редактируйте их вручную. `i18n.js` отвечает за переключение языков, `tools/content-selectors.json` связывает названия полей с элементами страницы.

Старая копия `assets/Симагамбетов_Нартай_CV.pdf` оставлена для совместимости с прежними прямыми ссылками. Кнопка сайта использует только `assets/cv.pdf`; при сборке копия тоже обновляется автоматически.

## AI-помощник

Чат работает в текстовом режиме. Слева от «Отправить» находится единственная кнопка «Скачать CV». Микрофона, браузерной озвучки и настроек голосов нет. На телефоне окно учитывает visualViewport: отправка остаётся над экранной клавиатурой, а при открытии чата клавиатура не появляется сама.

У каждого ответа есть динамик: по нажатию сервер генерирует аудио через Gemini TTS. Текст показывается сразу, без ожидания звука. Повторное нажатие останавливает воспроизведение. При ошибке воспроизведения текст остаётся доступным. Некоторые мобильные браузеры могут потребовать повторного нажатия для запуска аудио.

API размещён в отдельном Docker-контейнере на VPS:

- https://kinbridge.us/api/cv-chat — ответы по CV.
- https://kinbridge.us/api/cv-speech — WAV-озвучка ранее выданного ответа по answerId. Произвольный текст озвучивать нельзя.
- Настройки виджета: assistant.enabled, assistant.endpoint и assistant.speechEndpoint в content.json.
- Ключ хранится только в приватном ~/vcard-assistant/.env на сервере. Не помещайте ключи в content.json или Git.
- Озвучка: Gemini 3.8 Flash-Lite TTS, голос Kore. Серверные переменные GEMINI_TTS_MODEL и GEMINI_TTS_VOICE позволяют менять модель и голос. Это голос Gemini API, совпадение с конкретным голосом приложения Gemini не гарантируется.
- Доступ к озвучке ответа действует 10 минут. Сервер хранит до четырёх аудиоответов в памяти; перезапуск сбрасывает кеш. Запросы TTS используют store=false.
- publish.cmd обновляет сайт и данные CV на сервере через SSH-подключение my-vps. Замена PDF отдельно не меняет факты в content.json.

Короткие вопросы про DevOps, SQL, руководство и AI отвечаются сразу из данных CV. Другие вопросы обрабатывает Gemini с минимальным уровнем рассуждения и ограничением ожидания 15 секунд. Пока запрос выполняется, можно отправить новый — предыдущий отменится. Генеративные ответы могут ошибаться; проверяйте их по CV.

Локальный запуск (Node.js 22+, без npm install):

```powershell
node --env-file="D:\project\Assistant\system\assistant\.env" assistant/server.mjs
```

Откройте http://localhost:8787. Для локальной проверки можно задать endpoint и speechEndpoint на http://localhost:8787/api/chat и http://localhost:8787/api/speech соответственно, затем пересобрать сайт. Публичный сайт использует HTTPS.

Проверки:

```powershell
node --test assistant/*.test.mjs
node tools/check-content.cjs
.\tools\build.ps1 -Check
```

На сервере:

```sh
cd ~/vcard-assistant
sudo docker compose -p vcard-assistant -f assistant/compose.yml ps
sudo docker compose -p vcard-assistant -f assistant/compose.yml logs --tail 30
```

Для обновления кода передайте папку assistant на сервер и выполните sudo docker compose -p vcard-assistant -f assistant/compose.yml up -d --build. Данные читаются из data/content.json без пересборки. Маршруты Nginx находятся в assistant/nginx-location.conf. Порт контейнера 8787 доступен только на loopback; Nginx ограничивает частоту запросов.

## Предложения в Telegram

Кнопка «Оставить предложение» в чате открывает форму имени, контакта и сообщения. Посетитель отмечает согласие, проверяет предварительный просмотр и отдельно подтверждает отправку. В Telegram передаются только эти поля; история чата не прикладывается и данные формы не отправляются в Gemini.

API: https://kinbridge.us/api/cv-contact. Токен и фиксированный получатель хранятся в закрытом ~/vcard-assistant/telegram.env на сервере; этот файл подключается через Docker Compose и исключён из Git и контекста сборки. Повтор одного requestId не создаёт новое сообщение. При неопределённом результате доставки автоматическая повторная отправка не выполняется. Состояние отправок хранится в памяти до 24 часов и сбрасывается при перезапуске контейнера. Лимит — 10 предложений за 5 минут для всего сервиса, дополнительно действуют ограничения Nginx.

Если сеть блокирует kinbridge.us, запрос формы не достигает сервера. В этом случае интерфейс сохраняет текст, предлагает скопировать сообщение и открыть публичный Telegram Нартая напрямую. Этот путь требует ручной отправки посетителем.
