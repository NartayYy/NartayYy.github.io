# Обновление сайта

Требуются Python 3, Git и настроенный доступ к GitHub.
Все команды ниже запускаются из папки проекта в PowerShell.

## Обновить CV

```powershell
.\update-cv.cmd "D:\Мои доки\Симагамбетов_Нартай_CV.pdf"
```

Команда проверит PDF, заменит `assets/cv.pdf` и обновит версию ссылки по содержимому файла, чтобы браузер скачивал новую версию.

Обновить и сразу отправить на GitHub:

```powershell
.\update-cv.cmd "D:\Мои доки\Симагамбетов_Нартай_CV.pdf" -Publish
```

CV и текст сайта обновляются отдельно: загрузка PDF не извлекает из него данные.

## Изменить данные

Редактируйте `content.json` в любом текстовом редакторе:

- `contacts` — телефон, подпись телефона, email, ссылки Telegram и WhatsApp.
- `cv` — путь к PDF и имя при скачивании.
- `photo` — путь к фотографии.
- `educationYears` — годы окончания обучения.
- `stack` — технологии, сгруппированные по категориям.
- `languages.ru`, `languages.kk`, `languages.en` — тексты на трёх языках.
- В каждом языке `title`, `description`, `aria` — заголовок, описание и подписи доступности.
- В `sections`: `position` — должность, `tagline` — краткое описание, `about` — о себе; `experienceDates`, `experienceCompanies`, `experienceRoles`, `experienceDetails` — опыт работы.

Например, должность:

```json
"position": ["Руководитель ИКТ · DevOps / DBA"]
```

Каждый элемент `experienceDetails` — массив отдельных достижений для одного места работы. Можно добавлять и удалять достижения в этом массиве. В остальных массивах сохраняйте количество и порядок элементов: они соответствуют существующим блокам сайта. Новое место работы или раздел требует изменения шаблона.

Тексты могут содержать HTML, например `<br>` или существующие счётчики `<span class="counter" ...>`. Сохраняйте их при редактировании. Общие контакты, стек и годы меняются один раз; переводимые тексты редактируются на каждом языке.

Собрать сайт и проверить данные:

```powershell
python tools/build.py
python tools/build.py --check
```

Откройте `index.html` в браузере для предварительного просмотра — работает и без локального сервера.

## Опубликовать

```powershell
.\publish.cmd
```

Команда соберёт и проверит сайт, создаст коммит и отправит текущую ветку в GitHub. Публикация на сайте зависит от настроенной ветки GitHub Pages; для этого проекта используется `main`. Если есть ранее подготовленные к коммиту изменения, команда остановится, чтобы не включить их случайно. При ошибке отправки локальный коммит сохранится — команду можно повторить.

## Для разработки

`content.json` — источник данных. `tools/index.template.html` — шаблон оформления. `index.html` и `content.js` создаются сборкой: не редактируйте их вручную. `i18n.js` отвечает за переключение языков, `tools/content-selectors.json` связывает названия полей с элементами страницы.

Старая копия `assets/Симагамбетов_Нартай_CV.pdf` оставлена для совместимости с прежними прямыми ссылками. Кнопка сайта использует только `assets/cv.pdf`; при сборке копия тоже обновляется автоматически.

## Голосовой помощник

На сайте есть кнопка «AI-помощник»: вопрос можно написать или произнести через микрофон. Gemini отвечает по данным сайта; браузер озвучивает ответы, если включена соответствующая опция. Это распознавание речи + текстовый Gemini + голос браузера, а не Gemini Live. Доступность голосового ввода и голосов (в том числе казахского) зависит от браузера и ОС. При отсутствии поддержки остаётся текстовый ввод. Разговор хранится только в памяти вкладки, закрытие прекращает запись и озвучивание.

- API: https://kinbridge.us/api/cv-chat — отдельный Docker-контейнер на VPS, через существующий Nginx и HTTPS.
- Ключ Gemini находится только в приватном файле ~/vcard-assistant/.env на сервере. Не добавляйте ключи в content.json или Git.
- Настройки виджета: assistant.enabled и assistant.endpoint в content.json.
- publish.cmd также обновляет данные CV на сервере через SSH-подключение my-vps. Доступ по ключу должен быть настроен. Изменение PDF само по себе не меняет факты в content.json.
- Порт контейнера 8787 открыт только на loopback. Ограничения: 10 запросов в минуту на IP в Nginx (с небольшим запасом), общий лимит API 20 запросов в минуту, до 8 одновременных запросов.
- По вопросам вне CV помощник должен честно сообщать, что данных нет. Генеративные ответы всё равно могут ошибаться.

Запуск локально (Node.js 22+, без npm install):

```powershell
node --env-file="D:\project\Assistant\system\assistant\.env" assistant/server.mjs
```

Откройте http://localhost:8787. Если действующая сеть блокирует kinbridge.us, для локальной проверки временно задайте assistant.endpoint: "http://localhost:8787/api/chat" и пересоберите сайт. Публичный сайт должен использовать HTTPS API.

Проверки:

```powershell
node --test assistant/server.test.mjs
node tools/check-content.cjs
.\tools\build.ps1 -Check
```

На сервере:

```sh
cd ~/vcard-assistant
sudo docker compose -p vcard-assistant -f assistant/compose.yml ps
sudo docker compose -p vcard-assistant -f assistant/compose.yml logs --tail 30
```

Для изменения кода API передайте папку assistant на сервер и пересоберите контейнер командой sudo docker compose -p vcard-assistant -f assistant/compose.yml up -d --build. Данные читаются из data/content.json без пересборки. install-nginx.py добавляет маршрут только в конфигурацию kinbridge.us и сохраняет резервную копию; выполнять его нужно только при первоначальном подключении маршрута.

### Голос и быстрые ответы

В меню «Голос» можно выбрать доступный голос браузера и проверить его кнопкой «Прослушать». Выбор сохраняется отдельно для каждого языка. Количество и звучание голосов зависят от устройства и браузера.

Короткие типовые вопросы про DevOps, SQL, руководство и AI отвечаются сразу из актуальных данных CV. Сложные и неоднозначные вопросы обрабатывает Gemini с минимальным уровнем рассуждения и ограничением ожидания 15 секунд. Во время ожидания можно отправить новый вопрос: предыдущий запрос отменяется.
